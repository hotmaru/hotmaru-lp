# ほっとまる株式会社 公式ホームページ

公開URL: https://hotmaru.netlify.app/

このリポジトリの main ブランチにファイルを保存（Commit）すると、Netlify が自動でサイトに反映します。

## 編集のしかた
1. 直したいファイル（例: `index.html`）を開く
2. 右上の鉛筆マーク（Edit）を押して修正
3. 「Commit changes」で保存 → 1〜2分でサイトに反映

## 消してはいけないファイル
- `google286b964d9ffc4381.html`（Google Search Console の所有権確認）
- `robots.txt` / `sitemap.xml`（検索エンジン向け設定）
- `_headers`（お礼ページ /thanks を検索に出さない設定）

## 画像を追加するとき
`images` フォルダを開き、右上の「＋」または「Add file」→「Upload files」でアップロードします。
